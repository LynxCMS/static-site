# lynxcms/static-site

> [!NOTE]
> This is a read-only split of [`packages/static-site`](https://github.com/LynxCMS/lynxcms/tree/main/packages/static-site) in the [Lynx CMS monorepo](https://github.com/LynxCMS/lynxcms). Open issues and pull requests there. Lynx is not ready for production yet: see its README.

Exports a Lynx CMS site as static files: every published page in every language, the public files, a 404 page and redirects, to host without PHP.

## Installing

Lynx is not on Packagist yet: see [Trying it](https://github.com/LynxCMS/lynxcms#trying-it) in the monorepo's README.
